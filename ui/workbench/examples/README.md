# Harbor Light

Original, authored example for the GuitarOCR editor: one page, eight bars,
guitar and bass. The source image and preset score data are dedicated to the
public domain under CC0-1.0 and may be used, modified, and redistributed.

This is a synthetic preset, not an OCR result or an OCR accuracy benchmark.
Opening, editing, reviewing, and exporting it needs no inference model.

`Harbor-Light-synthetic-project.zip` is a normal GuitarOCR project archive. The
workbench imports a fresh copy using the same validated route as project backups;
the bundled archive is never changed by editing that copy.

GuitarOCR 使用说明

Windows 10 / 11（64 位）

1. 将 ZIP 完整解压到可写文件夹，例如 D:\GuitarOCR。
2. 双击文件夹中的 start.bat。
3. 首次启动会联网安装 Python、依赖和 GLM-OCR 基座，需要下载数 GB。
   请预留至少 20 GB 磁盘空间，保留启动窗口并等待浏览器自动打开。
4. 在网页中导入 PDF 或图片，校对识别结果，下载 GP5。

以后仍双击 start.bat。首次安装中断后可重跑同一个文件。
使用期间保留启动窗口，关闭窗口会停止服务。

包内已包含版面模型和两套 OCR 适配器，无需安装 Git 或提前安装 Python。
NVIDIA 驱动 580 或更新版本可自动使用 GPU，否则使用 CPU，识别会较慢。

Linux x64

在解压后的文件夹中打开终端，运行 bash start.sh。
Ubuntu / Debian 如提示缺少系统库，执行：
sudo apt-get install curl ca-certificates libgl1 libglib2.0-0

使用帮助

网页地址：http://127.0.0.1:7860
可先导入 examples 文件夹中的 demo.pdf 试用。
模型主要适用于规则排版的 TAB、五线谱和混合吉他谱，识别后需要校对。
详细操作见 docs/webui.md，安装问题见 docs/troubleshooting.md。
安装日志在 output/logs，已保存的项目在 output/webui。
更新版本前，可在网页导出页下载项目备份，更新后恢复。

下载与问题反馈：https://github.com/Flurry-L/guitarOCR

GuitarOCR Python 启动 ZIP 使用说明

本文件适用于 start.bat / start.sh 研究、命令行和服务入口。
当前源码的原生桌面客户端使用 Tauri + Rust，不通过这些脚本启动，也不安装 Python。
已发布 0.1.0 安装包早于当前原生改动，下载前请看 README.md 和 docs/setup.md。

Windows 10 / 11（64 位）

1. 将 ZIP 完整解压到可写文件夹，例如 D:\GuitarOCR。
2. 双击 start.bat。脚本安装所选引擎对应的 Python 环境和模型。
3. 保留启动窗口，等待浏览器打开；在网页中导入 PDF 或图片、校对并导出。

Linux x64

在解压后的文件夹中运行 bash start.sh。
Ubuntu / Debian 如提示缺少基础下载工具，安装 curl 和 ca-certificates。

环境与模型

引擎、平台支持、下载容量和磁盘要求以 docs/setup.md 为准。
默认轻量引擎需要已核验的预编译 llama.cpp 附件；未发布的平台不会自动编译或下载未知程序。
仅校对已有项目，可在已安装基础依赖的研究环境运行 guitarocr-web --edit-only，不加载模型。
下载中断后可重跑相同脚本；更新代码复用兼容的模型与依赖。
Python 依赖优先从国内源下载，失败后尝试官方源；GitHub 附件、uv 和 Windows C++ 运行库使用官方站点。

运行与备份

网页默认地址：http://127.0.0.1:7860
使用期间保留启动窗口；关闭窗口会停止 Python 本机服务。
默认日志在 output/logs，项目在 output/webui。更新前从网页导出项目 ZIP 备份。
停止服务后，可运行 scripts/bootstrap.sh status / clean 查看和清理旧 Python 环境；不会删除项目或模型缓存。

模型识别后需要校对。操作见 docs/webui.md，安装与故障处理见 docs/setup.md。
项目与问题反馈：https://github.com/Flurry-L/guitarOCR

同日后续的开源审核将 Pillow 升至 12.3，并整理共用几何与模型池逻辑；44 项测试、2 项浏览器回归及真实 PDF / 图片示例通过，细节和剩余问题见 [审核记录](open-source-audit.md)。下文原始记录和 `validation-example.json` 保留原验证时的数值。

## 安装与软件行为

- Linux x64 / Python 3.11：在独立目录实际运行一键 CPU 安装、重复安装、CPU 切换 CUDA、环境与 SHA-256 检查、启动。默认安装目录也完成 CUDA 安装。Paddle CPU 使用真实发布权重完成图片定位；新安装的 CUDA 环境完成 PDF 和图片到 GP5 的实际推理。
- 安装验证复用了本机 GLM 基座文件，没有重复下载约 2 GB 的模型；另行核对了 Hugging Face 固定 revision 的文件大小与远端 LFS SHA-256，均与安装清单一致。
- 全新轻量开发环境：按 uv.lock 安装，仅启用 webui / dev，确认没有 Torch；37 项核心、API、数据构建、评测上下文及安装器测试通过（含补充的 Linux 立即重启回归）。
- Chromium：两项浏览器场景覆盖四页 PDF、翻页、拖框、信息与音符编辑、旧标签页冲突、失败检测后手动画框恢复、GP5 下载和新文件导入提示。
- 真实浏览器与模型：上传示例 PDF、自动定位和识别、逐小节人工校对、下载 GP5，并重新读取验证标题与小节数量，全部通过；浏览器没有 JavaScript 错误。
- wheel 构建与静态资源、阶段配置、原生源码完整性检查通过；安装 wheel 后从仓库外验证各阶段导入、WebUI 路由与前端模块可用。
- Windows 安装脚本与原生 MSVC 编译尚未在本机实测，已提供对应 CI 入口。CI 未运行前不能将配置存在视为平台验证通过。

## 真实模型示例

模型文件、基座 revision、输入哈希和完整指标见 [机器可读记录](validation-example.json)。自编 First Steps 只有四小节，不是代表性测试集。

环境：Linux x64、Python 3.11.14、NVIDIA H100 80 GB，Torch 2.14.0、Transformers 5.8.0、PEFT 0.18.1。GLM 使用 GPU，图片版面检测使用独立 Paddle CPU 环境。输入与参考输出位于 examples/。

| 输入 | 检测小节 | 完整流程耗时 | GP5 写出 | 完全匹配小节 |
| --- | --- | --- | --- | --- |
| demo.pdf | 4 / 4 | 16.0 秒 | 成功 | 0 / 4 |
| demo.png | 4 / 4 | 16.9 秒 | 成功 | 3 / 4 |

两个案例合计的 PyTorch 峰值已分配显存约 2.26 GiB；这不包含全部 CUDA 驱动、预留显存和 Paddle 内存，不能直接视为最低显存要求。耗时包含各次模型加载，其他设备和曲谱长度会不同。

PDF 的自动结果包含多余声部休止和首小节识别错误；图片首小节把拍号中的数字误读为音符。结构校验都通过，说明语法和约束校验无法发现所有识别错误。案例在未人工修改时统计，未剔除失败小节，GP5 成功写出也不等于转录正确。

这些结果说明应保留逐步校对流程，并分别报告定位、音符、节奏及整谱效果。正式公开模型的总体准确率、独立测试集效果、消费级显卡耗时和最低资源要求仍待补充。训练损失、发布门槛以及此前四页 95 个检测框，都不能代替这些指标。

复现命令见 [训练与评测](training.md)。如果模型、示例、裁图规则或依赖发生变化，应重新生成记录。

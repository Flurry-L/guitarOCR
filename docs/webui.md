# 工作台使用说明

Windows 双击 `start.bat`，Linux 执行 `bash start.sh`，然后访问 http://127.0.0.1:7860。首次安装和启动参数见[安装说明](setup.md)。

## 导入乐谱

选择或拖入 PDF、PNG、JPG、BMP、TIFF，调整文件顺序后点击「导入乐谱」。PDF 和多页 TIFF 自动展开。每个项目最多 100 页、200 MB，单页最多 4000 万像素。

已保存的项目可以从导入页重新打开，刷新页面也会恢复当前项目。点击「导入新乐谱」开始另一份乐谱。

## 检查区域

点击「自动检测」。每个绿色框对应一个小节；混合谱的五线谱和 TAB 应放在同一个框内。蓝色谱头框用于读取曲名、作者和调弦，棕色框用于读取速度。

拖动框可移动，拖动四角可缩放。漏检时选择「＋ 小节框」补画；误检时选中后删除。侧栏的「前移」「后移」调整同页同类区域的阅读顺序，「精确位置」可输入原图像素坐标。通过缩略图或翻页按钮检查其他页面，完成后点击「保存并继续」。

「整份谱面」默认自动判断，选中小节后可单独纠正其类型。手动选择整份谱面的类型会应用到所有小节。自动检测失败时仍可手动画框。

## 校对谱面信息

点击「自动读取信息」，或直接填写曲名、作者、速度、变调夹和调弦。调弦按第 1 弦到低音弦排列，常用调弦可从列表选择；自定义调弦使用 MIDI 音高编号，例如标准吉他为 `64,59,55,50,45,40`。

核对后点击「保存并继续」。修改调弦需要重新识别小节。

## 识别与校对小节

点击「识别小节」，完成后逐小节对照原图检查。编辑方式可选「音符表格」或「小节文本」，修改后点击「保存小节」。切换编辑方式前需保存当前修改。

表格中的起点以四分音符拍数表示，从 0 开始。音符输入随谱面类型变化：

| 谱面类型 | 示例 | 含义 |
| --- | --- | --- |
| TAB | `1:3,2:1` | 第 1 弦第 3 品与第 2 弦第 1 品 |
| 五线谱 | `67,60` | MIDI 音高 G4 与 C4 |
| 五线谱＋TAB | `1:3:67` | 第 1 弦第 3 品，音高 G4 |

表格编辑会保留已有奏法和连音参数。需要修改奏法、连音或反复记号时，选择「小节文本」，格式见[参考文档](score-text.md)。保存时会检查格式和音乐约束；音高等识别错误仍需对照原图发现。

识别失败的小节暂用休止符占位，并标为「待检查」。可以重新识别，或手动修改后「保存并确认」。全部确认后才能导出。

识别期间点击「停止识别」，会在当前模型调用结束后停止并保存已完成部分；稍后点击「继续识别」。完成后可重试待检查小节或当前小节。重新识别全部小节会替换人工编辑，执行前会要求确认。修改小节不会自动重识别后续内容，跨小节连线等变化需要一并检查相邻小节。

## 导出与备份

点击「前往导出」，生成并下载 GP5。也可下载 `score.txt` 查看小节文本，或下载项目备份 ZIP。在另一台工作台的导入页选择「恢复项目备份」，即可继续处理原图和已保存的编辑。

GP5 使用 cp936 字符编码，无法写入的文字会有提示；小节文本保留原文。项目备份还包含校对状态，因此需要继续编辑时应保留 ZIP。

保存结果位于 `output/webui/<项目编号>/`。地址栏链接可加入书签。删除项目会同时删除上传文件、识别结果和导出文件，操作前会要求确认。

## 保存与重新处理

| 修改内容 | 保存后需要重新处理 |
| --- | --- |
| 区域或谱面类型 | 谱面信息、小节识别、GP5 |
| 调弦 | 小节识别、GP5 |
| 曲名、作者、速度、变调夹 | GP5 |
| 小节内容 | GP5 |

同一项目在多个标签页中编辑时，旧页面不能覆盖新版本。发生冲突时，先复制需要保留的修改，再重新载入项目。

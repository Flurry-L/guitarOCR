# 工作台使用说明

桌面端、本地网页和多人服务共用以下校对界面。启动方式见[安装说明](setup.md)。

## 导入乐谱

选择或拖入 PDF、PNG、JPG、BMP、TIFF，调整文件顺序后点击「开始识别」，后台自动完成区域检测、谱面信息和音符识别。需要手动控制时选择「先导入，手动检查区域」。PDF 和多页 TIFF 自动展开。每个项目最多 100 页、200 MB，单页最多 4000 万像素，所有页面合计最多 2 亿像素。

侧栏「项目库」支持按名称搜索、按状态筛选和排序，导入页显示最近项目。刷新页面会恢复当前项目与进度。「任务中心」可查看和停止任务，中断的一键任务可继续识别。「新建项目」开始另一份乐谱。

「设置」显示运行设备、模型安装状态和上传限制，可切换浅色、深色或跟随系统。外观偏好保存在当前浏览器。

## 检查区域

点击「自动检测」。每个蓝色框对应一个小节；混合谱的五线谱和 TAB 应放在同一个框内。灰蓝色谱头框用于读取曲名、作者和调弦，棕色框用于读取速度。

谱号框应完整包含谱号及旁边的八度数字，支持 G、F、C 谱号和鼓谱号。移调标记框应包含移调说明，或完整的 8va／8vb 延长线；漏检时可从绘框菜单补画。

选中区域后可查看裁图预览。拖动框可移动，拖动四角可缩放，工具栏支持撤销和重做。漏检时选择「＋ 小节框」补画；误检时选中后删除。侧栏的「前移」「后移」调整同页同类区域的阅读顺序，「精确位置」可输入原图像素坐标。通过缩略图或翻页按钮检查其他页面，完成后点击「保存并继续」。

「整份谱面」默认自动判断，选中小节后可单独纠正其类型。手动选择整份谱面的类型会应用到所有小节。自动检测失败时仍可手动画框。

## 校对谱面信息

点击「自动读取信息」，或直接填写曲名、作者、乐器和速度。吉他、贝斯还需核对调弦与变调夹。调弦按第 1 弦到低音弦排列，列表提供常见吉他、贝斯调弦；自定义调弦使用 MIDI 音高编号，例如五弦贝斯为 `43,38,33,28,23`。仅有五线谱时通常无法确定实际弦数和调弦，需要自行确认。

总谱可切换音轨，分别核对名称、乐器、MIDI 音色和调弦。钢琴左右手归入同一音轨，谱表分别显示；速度对整份乐谱生效。

「记谱移调」可留空，使用谱面中读取的说明；没有印出的移调量需手填，例如降 B 调小号填 -2。8va／8vb 按谱中的范围作用于相应小节。变调夹品位可自动读取，也可手工修正。

核对后点击「保存并继续」。修改乐器、调弦或记谱移调需要重新识别小节。钢琴和鼓组使用五线谱模式。

## 校对整份乐谱

点击「识别乐谱」，结果按阅读顺序排成整谱。识别失败或节奏冲突的小节标红，需要核对移调、谱号等信息的小节标黄。「下一个待检查小节」可直接定位问题，其他小节也可点击编辑。

音轨选择器可聚焦单轨或查看全部音轨；小节导航按音轨和谱表分组，可筛选待检查或已确认的小节。「确认并检查下一个」用于连续校对问题小节，快捷键可在顶栏查看。

整谱由 alphaTab 排版，原谱随选中小节切换，点击原图可放大；窄屏时用工具栏的「原谱」打开对照图。直接点选谱面中的音符，用固定工具栏修改时值、附点、连音、奏法，或增删音符、整拍。谱面大小可调，支持撤销和重做。

- TAB：点击弦位，再用品位栏或数字键输入 0 至 30，`X` 表示闷音。上下键换弦，左右键换拍。
- 五线谱：双击谱表空位添加音符；选中音符后可上下拖动，或用升降半音按钮、上下键、音高栏修改。混合谱同步调整弦位和品位。
- 鼓谱：点选鼓音后在鼓件栏更换，或向当前拍添加鼓件。

按 Delete 删除选中音符；删除最后一个和弦音后，该拍保留为休止符。工具栏可切换或添加声部，每个谱表最多 16 个声部。「拍号、速度与起点」中可修改当前小节和音符起点，起点以四分音符拍数计算，从 0 开始。更改时值会移动后续音符。

点击「保存并确认」，或按 Ctrl / ⌘ + S，保存当前修改并确认小节。切换小节、切换编辑方式或导出时，也会先保存有效修改；待检查标记需点击「确认小节」清除。校验失败或版本冲突时保留草稿并显示原因，可选择「放弃修改」重新载入已保存的内容。保存和切换小节后仍可撤销本次打开项目后的谱面编辑。刷新页面恢复已保存内容，离开前若有未保存修改会提醒。

工具栏可修改延音线、击勾弦、滑音、掌闷音、颤音、断奏、重音和常用推弦。反复记号及其他奏法参数可在「小节文本」中修改，格式见[参考文档](score-text.md)。未在工具栏展示的原有字段会保留；装饰音的部分细节尚未绘制，需对照原谱。

识别期间点击「停止识别」，当前模型调用结束后保存已完成部分，稍后可继续。也可重新识别单个小节或所有待检查小节；重新识别会替换对应的人工编辑。修改小节不会自动重识别后续内容，跨小节连线需要一并检查邻近小节。

## 导出与备份

点击「导出乐谱」，生成并下载 GP5，也可下载 MusicXML 或独立乐谱 JSON。GP5 对超出单轨声部、弦数或音域限制的内容自动拆成同步音轨。文件名使用曲名，曲名为空时使用上传文件名，自动处理系统不允许的字符。也可下载 `score.txt` 查看小节文本，或下载项目备份 ZIP。在另一台工作台的导入页选择「恢复项目备份」，即可继续处理原图和已保存的编辑。

GP5 使用 cp936 字符编码，无法写入的文字会有提示；小节文本保留原文。项目备份还包含校对状态，因此需要继续编辑时应保留 ZIP。

保存结果位于 `output/webui/<项目编号>/`。地址栏链接可加入书签。删除项目会同时删除上传文件、识别结果和导出文件，操作前会要求确认。

## 保存与重新处理

| 修改内容 | 保存后需要重新处理 |
| --- | --- |
| 区域或谱面类型 | 谱面信息、小节识别、GP5 |
| 乐器、调弦、记谱移调 | 小节识别、GP5 |
| 曲名、作者、速度 | GP5 |
| 变调夹 | 五线谱和混合谱需核对音高，再导出 GP5 |
| 小节内容 | GP5 |

同一项目在多个标签页中编辑时，旧页面不能覆盖新版本。发生冲突时，先复制需要保留的修改，再重新载入项目。

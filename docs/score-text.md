# 小节文本格式

小节文本记录音符、节奏和奏法。每个小节占一行 UTF-8 文本，以 `MEASURE`（小节）开头；整首谱按阅读顺序逐行排列，下载文件为 `score.txt`。高级编辑、文本下载和 GP5 导出使用同一套可读名称。

```text
MEASURE time=4/4 tempo=120 | V0{@0:q:s1f0 @960:q:s2f1 @1920:h:r}
```

它表示 4/4 拍、四分音符 120 BPM：第一拍弹第 1 弦空弦，第二拍弹第 2 弦第 1 品，第三拍开始休止两拍。

## 单位和声部

- `@数字` 是小节内的起点，四分音符为 **960 ticks**。WebUI 表格显示四分音符拍数，保存时换算为 ticks。
- `V0{...}` 是声部 0；多个声部用 ` || ` 分隔。GP5 导出支持 `V0`、`V1` 两个声部；重复声部或更多声部会报错，避免导出时丢音。
- 第 1 弦是最高弦；调弦数组同样按最高弦到最低弦排列。
- TAB 音符使用 `s1f3`；纯五线谱使用 MIDI 音高 `p67`；混合谱可写 `s1f3p67`。和弦用逗号分隔，如 `s1f0,s2f1,s3f0`。

## 时值

| 标记 | 音符 |
| --- | --- |
| w / h / q | 全 / 二分 / 四分 |
| e / s / t / f | 八分 / 十六分 / 三十二分 / 六十四分 |
| q. / q.. | 附点 / 双附点四分 |
| e[3:2] | 三连音：3 个八分音符占 2 个八分音符时值 |

`r` 表示休止，`e` 表示空拍状态。`^` 重复同一声部前一个事件的音符与奏法，但使用当前事件的起点及时值；不能放在该声部首个事件。

## 常用字段与奏法

小节头部支持 `time`、`tempo`、`key`、`feel`、`bar`、`rep`、`alt`、`section`、`dir`、`from`。缺省拍号沿用上下文，完整乐谱应给首小节明确拍号。section 等文字使用 URL 百分号编码。

`feel=eighth` / `feel=sixteenth` 表示当前小节采用八分／十六分 swing。它是逐小节状态：正常目标中省略 `feel` 或显式写 `feel=none` 都表示直拍，不无限沿用历史 swing。识别失败的休止占位暂时保留紧邻前一小节的 feel，并继续标记为需复核，避免一次失败切断后续 swing 前文；若失败的小节恰好改变了演奏方式，仍需人工校正。

音符级奏法放在圆括号中，例如 `s1f3(vib)`、`s2f5(hammer)`、`s3f2(pm,let)`。常见标记包括 tie、dead、vib、hammer、ghost、pm、stacc、let、accent、sl / ss 及 harm 等。事件级奏法放在尖括号中，例如 `<dyn:70>`。具体参数映射见 `gp5_export/effects.py`；使用 WebUI 普通表格编辑时会保留已有奏法参数。

装饰音可以携带参数。例如混合谱的 `grace:f5p69:hammer:0:0` 表示第 5 品、MIDI 音高 69、击弦连接、拍前且非死音。纯 TAB 写作 `grace:f5:hammer:-:0`，其中 `-` 表示从 TAB 无法判断是否占拍；纯五线谱位置写作 `p69`，不会要求模型猜隐藏指法。死装饰音位置写作 `x`。`trill:f9` 保存 TAB 可见的辅助品位，纯五线谱只保留 `trill`。`trem:32` 保存谱面可见的震音细分时值。

Guitar Pro 原生渲染对照确认，装饰音播放时长和颤音播放速度不改变打印像素，因此不作为 OCR 目标。手工记录仍可使用完整形式 `grace:f5p69:32:hammer:0:0`、`trill:f9p73:32`；调用格式化函数时指定 `preserve_playback=True` 可保留这些参数。缺省导出采用三十二分细分。旧文件中的裸 `grace`、`trill`、`trem` 仍能读取；它们没有记录完整参数，导出时采用默认值。

`bend:prebendRelease:100` 等推弦标记按类型恢复上推、回落或预推轮廓；任意原始控制点曲线仍不能无损还原。小节文本也不是 GP 所有播放参数的存档格式。GP8 会打印 `p`、`f` 等力度符号，但源文件逐音的 MIDI 力度不等于每个音都印有力度标记；当前 OCR 数据尚未按实际打印位置标注力度变化，导出时可用已有的 `dyn` / `vel` 手工补充。

小节内显式起点 `@960` 之前的空隙会在 GP5 中补休止，避免因 GP5 的隐式时序把音符前移。同一声部的重叠事件会报错；无法在当前调弦上演奏的纯五线谱音高或和弦也会报错，需校正音高或调弦。

GP5 表示能力与原始谱面并非完全一致。请对照原图检查连线、反复、变调夹和复杂技巧。GP5 文字编码使用 cp936，无法表示的字符会列入 `.encoding.json`；小节文本保留原文。

## 格式与模型输出

语法有效不等于识别正确。模型输出经过结构与节奏约束检查；多次失败后生成休止占位，并在识别清单中标记 needs_review、fallback_reason、review_measures。WebUI 必须逐小节确认后导出。小节文本文件本身不承载这些校对状态，因此备份工作时优先下载完整项目 ZIP。

格式前缀必须恰好是 `MEASURE`。未知或重复的小节头字段会报错，避免解析后静默丢失。原生 GP 的全空小节按打印的整小节休止生成标签。

识别时还会使用上一小节的“前文”摘要，显示标记为 `CONTEXT`。它只保留上一小节最后的事件及有效拍号、调号等状态，不是一个新小节，不应写入乐谱正文。谱面类型由版面检测传给 OCR，不由文本标记判断。

名称转换只发生在显示、编辑保存和导入导出边界，不改变音符、奏法或其他字段，不需要重新微调。模型的训练协议、提示词及权重保持原样。旧项目和旧格式文本仍可直接读取；完整项目 ZIP 保留兼容数据和校对状态。

将下载的小节文本转为 GP5：

```bash
uv run --no-sync python -m gp5_export.writer score.txt output/score.gp5 --mode tab
```

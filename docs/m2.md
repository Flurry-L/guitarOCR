# M2 小节格式

一个小节占一行 UTF-8 文本；整首谱按阅读顺序逐行排列。解析与格式化入口为 `shared.m2.parse_measure_target` / `format_measure_target`，音乐约束由 `shared.constraints.validate_measure_target` 校验。

```text
M2 time=4/4 tempo=120 | V0{@0:q:s1f0 @960:q:s2f1 @1920:h:r}
```

它表示 4/4 拍、四分音符 120 BPM：第一拍弹第 1 弦空弦，第二拍弹第 2 弦第 1 品，第三拍开始休止两拍。

## 单位和声部

- `@数字` 是小节内的起点，四分音符为 **960 ticks**。WebUI 表格显示四分音符拍数，保存时换算为 ticks。
- `V0{...}` 是声部 0；多个声部用 ` || ` 分隔。GP5 导出支持两个声部。
- 第 1 弦是最高弦；调弦数组同样按最高弦到最低弦排列。
- TAB 音符使用 `s1f3`；纯五线谱使用 MIDI 音高 `p67`；混合谱可写 `s1f3p67`。和弦用逗号分隔，如 `s1f0,s2f1,s3f0`。

## 时值

| 标记 | 音符 |
| --- | --- |
| w / h / q | 全 / 二分 / 四分 |
| e / s / t / f | 八分 / 十六分 / 三十二分 / 六十四分 |
| q. / q.. | 附点 / 双附点四分 |
| e[3:2] | 三连音：3 个八分音符占 2 个八分音符时值 |

`r` 表示休止，`e` 表示空拍状态。`^` 重复同一声部前一个事件的音符与奏法，但使用当前事件的起点及时值；不能放在该声部首个事件。

## 常用字段与奏法

小节头部支持 `time`、`tempo`、`key`、`feel`、`bar`、`rep`、`alt`、`section`、`dir`、`from`。缺省拍号沿用上下文，完整乐谱应给首小节明确拍号。section 等文字使用 URL 百分号编码。

音符级奏法放在圆括号中，例如 `s1f3(vib)`、`s2f5(hammer)`、`s3f2(pm,let)`。常见标记包括 tie、dead、vib、hammer、ghost、pm、stacc、let、accent、sl / ss 及 harm 等。事件级奏法放在尖括号中，例如 `<dyn:70>`。具体参数映射见 `gp5_export/effects.py`；使用 WebUI 普通表格编辑时会保留已有奏法参数。

GP5 表示能力与原始谱面并非完全一致。请对照原图检查连线、反复、变调夹和复杂技巧。GP5 文字编码使用 cp936，无法表示的字符会列入 `.encoding.json`；M2 保留原文。

## 格式与模型输出

语法有效不等于识别正确。模型输出经过结构与节奏约束检查；多次失败后生成休止占位，并在识别清单中标记 needs_review、fallback_reason、review_measures。WebUI 必须逐小节确认后导出。M2 文件本身不承载这些校对状态，因此备份工作时优先下载完整项目 ZIP。

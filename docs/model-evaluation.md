# 模型评测

结果对应 `parallel-score-2026-09-28` 默认权重。模型先在验证集选择，再评估完整留出集；原有曲谱、随机合成谱、奏法合成谱的训练／验证／测试曲源及曲源组交叉数均为 0。详细原始计数、分组结果和模型配置见 [小节评测记录](../weights/measure_ocr/evaluation.json)。

小节解码器读取当前及前后小节图像，拍号和调号由独立分类器批量读取并按谱序传播；跨节延音在生成后处理。小节之间并行，小节内部仍为自回归解码，使用任务训练后的原生 MTP。默认每批 64 小节、MTP 草稿长度 4，小节引擎上下文容量为 16,384 tokens，以容纳相邻图像和重试反馈。

以下裁图评估覆盖全部 102,767 个留出小节，按完整曲谱输入，不提供标注前文。裁图、乐器、调弦和移调上下文使用参考信息，拍号／调号由模型预测。核心匹配要求整小节的音符字段、节奏和元数据一致，完整匹配还要求规范化文本中的奏法一致；这些百分比不是逐音符准确率。

选定配置相对原串行模型加速 8.91 倍。MTP 经过主模型验证后接受草稿；不同批量和计算路径仍会带来少量浮点数值差异，配置选择要求核心与完整匹配均在普通解码的 0.1 个百分点以内。FP8 实测更慢且准确率下降，因此默认使用 BF16。

安装后的默认权重通过实际队列、工作区和导出流程识别 `jixian.pdf`：17 小节，预热后完整流程 3.60 秒，模型初始化另计 50.27 秒。导出的 GP5 已重新解析，音轨及小节数量一致。取消、断点续识别、指定小节重试及保留人工修改也经过实际工作流验证。

版面模型在 1,628 页留出数据上，小节数量完全正确的页面为 1,621 页（原模型 1,554 页），AP@[0.50:0.95] 为 86.59%（原模型 81.64%）。拍号／调号分类器评估包含全部 102,767 张留出裁图。

谱面信息模型使用全部 15,323 张留出裁图评估：调弦 1,767/1,767，速度 2,096/2,096，乐器 1,124/1,124，弦数 1,123/1,124，谱号及其八度各 8,536/8,536，变调夹 1,800/1,800，移调半音 1,785/1,800。详见 [谱面信息评测](../weights/document_info/evaluation.json)和[版面评测](../weights/layout/evaluation.json)。

数据以 Guitar Pro 原生排版、移调变体和模拟扫描为主；结果适用于这里覆盖的单轨、单谱表范围。复杂随机合成谱包含密集和弦、大跨度音高及少见打击乐符号，完整匹配还严格区分和弦中每个音符的奏法归属。上表保留该压力集的全部结果。

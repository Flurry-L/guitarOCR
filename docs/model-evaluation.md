# 模型评测

项目使用一套版面模型和两套 OCR 适配器。以下结果对应[模型清单](../weights/manifest.json)中的权重和基座哈希。

## 数据与评测范围

来源登记包含 7,114 个源文件标识、5,282 个曲源组，其中包括原曲、排版和移调变体。同曲音轨、排版及增强图保持在同一划分。页面由 Guitar Pro 原生渲染，模拟扫描包括缩放、模糊、阴影、噪声和 JPEG 压缩。

模型按验证集选择权重，再运行独立测试。小节 OCR 使用正确裁图；这部分指标不包含页面定位和谱面信息识别误差。手写、透视照片和真实扫描件的广泛适用性尚未验证。

## 版面检测

模型定位 TAB、五线谱、混合谱小节，以及速度、谱号和移调区域，共六类。以下结果使用实际后处理、置信度阈值 0.25；召回率使用 IoU 0.50。

| 独立测试 | 页数 | 小节召回率 | 移调框召回率 |
| --- | ---: | ---: | ---: |
| 原有乐器与排版 | 3,691 | 99.91% | 无该类标注 |
| 移调与八度标记 | 654 | 99.90% | 96.50% |
| 乐器名称移调说明 | 14 | 100.00% | 100.00% |

移调测试中，移调框 AP@[0.50:0.95] 为 70.68%，谱号框召回率为 99.85%。框已检出仍可能存在范围偏差，尤其需要检查跨小节的八度延长线。完整定位、谱面类型和数量指标见[版面评测记录](../weights/layout/evaluation.json)。

## 小节 OCR

核心匹配要求整个小节的音符字段、节奏和元数据一致，元数据包括速度、调号、swing 和反复。完整匹配还要求规范化文本中的奏法一致。百分比按小节计数，不是逐音符准确率。

独立小节使用标注前文、batch 8、单次贪心解码，上限 2,048 tokens。

| 独立小节测试 | 小节数 | 核心匹配 | 完整匹配 |
| --- | ---: | ---: | ---: |
| 乐器与弦数 | 2,258 | 93.80% | 92.38% |
| 吉他排版 | 1,800 | 92.67% | 84.44% |
| 模拟扫描 | 2,258 | 93.00% | 91.59% |
| 移调与八度标记 | 1,213 | 75.68% | 65.13% |

乐器与弦数测试分组如下：

| 乐器 | 小节数 | 核心匹配 | 完整匹配 |
| --- | ---: | ---: | ---: |
| 吉他 | 900 | 94.67% | 92.44% |
| 贝斯 | 1,158 | 95.51% | 94.56% |
| 鼓 | 100 | 70.00% | 70.00% |
| 钢琴、键盘单谱表 | 51 | 88.24% | 86.27% |
| 其他旋律乐器单谱表 | 49 | 91.84% | 91.84% |

移调测试另按乐器移调量分组，包含对应来源的休止小节和局部八度变体：

| 实音减记谱音高 | 小节数 | 核心匹配 |
| --- | ---: | ---: |
| -21 半音 | 120 | 40.83% |
| -14 半音 | 31 | 93.55% |
| -12 半音 | 480 | 83.12% |
| -9 半音 | 111 | 73.87% |
| -7 半音 | 120 | 56.67% |
| -2 半音 | 92 | 56.52% |
| 0 半音 | 79 | 84.81% |

带音高前文的旋律五线谱先输出记谱音高，再由代码按乐器移调、谱号八度和局部八度标记换算。谱号、音符位置或八度范围读错，仍会造成音高错误；格式检查无法排除这类错误。

连续识别使用完整来源、模型预测的前文和 batch 1，从首小节开始。它与独立裁图测试的曲源不同，不能用两组差异估算前文的影响。

| 连续独立测试 | 小节数 | 核心匹配 | 完整匹配 | 待检查 |
| --- | ---: | ---: | ---: | ---: |
| 乐器与排版 | 518 | 75.10% | 69.69% | 19 |
| 移调与八度标记 | 273 | 82.78% | 73.99% | 1 |

各弦数、钢琴与其他旋律乐器、技巧、原始输出合法率及验证结果见[小节评测记录](../weights/measure_ocr/evaluation.json)。

## 页面到 GP5

以下页面来自预留的测试来源，经过自动定位、类型判断、谱面信息读取、小节识别和导出。

| 页面 | 检出／预期小节 | 核心匹配 | 导出 GP5 |
| --- | ---: | ---: | --- |
| 七弦吉他混合谱 | 15/15 | 15/15 | 是 |
| 五弦贝斯 TAB | 24/24 | 24/24 | 是 |
| 鼓谱 | 36/36 | 18/36 | 是 |
| 钢琴单谱表 | 24/24 | 16/24 | 是 |
| 降 B 萨克斯 | 12/12 | 3/12 | 否 |
| F 调圆号（本页全为休止） | 12/12 | 12/12 | 是 |
| 降 E 萨克斯 | 12/12 | 2/12 | 是 |

降 B 萨克斯示例出现同声部事件重叠，系统保留识别结果并要求校对，暂不导出。F 调圆号页面只检验休止符和谱面信息，不能用来判断移调音符的准确率。

将成功导出的 6 份 GP5 重新导入 Guitar Pro，共 123 小节，音高、起点和局部八度标记与导出结果一致。这个检查验证文件保存，没有把识别错误算作正确音符。

这些页面是少量流程验收，不能替代独立测试。当前按单轨、单谱表处理，尚未实现钢琴双谱表或总谱的自动分组及多轨导出。GP5 最多保存七弦、每声部同时七个音符；超出限制时保留识别文本并报告导出失败。

没有印出的移调量需要手填。变调夹文字尚未训练，使用变调夹的五线谱或混合谱需要核对音高。力度尚未按实际打印位置监督，任意推弦控制点也未完整覆盖。颤音（trill）只有 10 条训练记录，含重复和增强，覆盖不足。导出前仍需对照原谱校对。

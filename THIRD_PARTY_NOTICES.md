# 第三方组件与许可

项目自身的许可证尚未选定。以下组件遵循各自许可，项目许可证不能改变它们的授权条件。

本文件集中保存模型、研究素材、图像处理适配和部分 Cargo 依赖的版权、来源及许可原文。
界面附带的 alphaTab 和 Bravura 字体声明见 [vendor/README.md](ui/workbench/vendor/README.md)。
打包时保留本文件，并从依赖发行包收集其余 Cargo、ONNX Runtime、PDFium 和 llama.cpp 的许可。
Python 研究环境的依赖许可证随各自软件包提供。

## 图像处理适配

`backend/src/image_transforms.rs` 的插值公式、精度、边界处理和量化行为参考并改写自：

- [OpenCV 4.13.0 resize.cpp](https://github.com/opencv/opencv/blob/4.13.0/modules/imgproc/src/resize.cpp)：`interpolateCubic`、`INTER_RESIZE_COEF_BITS`、`FixedPtCast`、`HResizeCubic`／`VResizeCubic` 和系数计算。仓库的 `research/common/images.py` 也采用这些公式。
- [Pillow 12.3.0 Resample.c](https://github.com/python-pillow/Pillow/blob/12.3.0/src/libImaging/Resample.c)：sinc／Lanczos 滤波、系数预计算、8 位量化与两遍重采样顺序。

GuitarOCR 于 2026 年改为 RGB8 Rust 数据存储与迭代、四行三次插值缓存及 i64 累加，去除了 C/C++、IPP／SIMD 和 Python 运行时依赖；Python 对照实现使用分块计算与整数累加。
OpenCV 的 Apache-2.0 项目许可和原 resize.cpp 的 BSD 风格版权声明均保留在下文；Pillow 保留 MIT-CMU 原文。

# 三种谱面的小节与类型检测：扩充训练版

一个 PP-DocLayoutV3 同时预测 `measure_tab`、`measure_notation`、`measure_both` 和 `tempo_region`。输入页面即可得到小节框及其谱面类型；混合谱的上下谱表属于同一个小节框。CLI、网页与整谱管线默认自动识别类型，每个小节的类型传给 GLM-OCR；用户仍可纠正类型。

## 数据与训练

2,799 个音乐来源按 family、音乐事件及标题别名检查分组：训练 2,400，验证 199，测试 200。所有页面由 Guitar Pro 原生渲染三种排版。训练使用 26,192 张干净页面和 6,548 张模拟扫描退化页面，合计 32,740 张；验证 2,337 页、测试 2,164 页。真实 GP 文件重新排版不等于真实扫描数据。

从上一版四类 typed 模型的最佳 EMA 参数继续训练，8 张 H100、每卡 batch 4、学习率 2e-5，共 6 轮。训练器按验证集四类 bbox AP 选择第 4 轮（95.3909%）；选定后才运行独立测试。可复现配置见 [training_config.yaml](training_config.yaml)，源谱索引见 [dataset_sources.json](dataset_sources.json)，哈希、完整指标和选择记录见 [evaluation.json](evaluation.json)。

## 实际流程验收与限制

项目默认 Paddle CPU 环境运行三种原生 PDF 各得到正确的 4 个小节；真实扫描 `jixian.pdf` 自动识别为混合谱、17 小节。验收时禁用了谱线规则类型分类器，确认类型来自模型。输入／权重哈希与运行结果保存在机器记录的 `cpu_acceptance`。80 项单元测试、3 项浏览器测试、Ruff 和环境／权重哈希检查通过。

页面与文档类型由小节检测分数加权汇总；投票占比不是校准概率。训练与测试以规则吉他单轨谱为主，不能据此保证手写、透视拍照、多音轨总谱或同页混排的准确率。历史 typed、多模式两类、纯 TAB 权重保留用于回退。

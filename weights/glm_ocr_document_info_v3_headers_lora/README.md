# 谱头与速度 OCR：多语言副标题修复版

这一份 LoRA 与小节 OCR 共用固定 revision 的 GLM-OCR 基座，负责可见的标题、作者、调弦标签和速度。副标题不应填入作者字段，缺失字段输出 `null`。它是原有谱面信息任务的新版本，不增加任务模型数量。

## 数据与训练

保留主语料 15,029 条训练裁图，再从原划分选择 120/30/30 个训练／验证／测试音乐来源，生成 180 个中英文元数据变体。每个变体由 Guitar Pro 原生渲染三种排版，共 540 份文档；原生 UTF-8 属性、PDF 文字与图像经过核对，没有使用 `jixian.pdf` 的标题、作者或图像训练。

原有训练样本加入 25% 扫描退化版本；新增谱头及其退化版本各重复 6 次。最终训练 23,808 条、验证 1,584 条、测试 1,536 条。验证与测试没有重复加权，来源 family 保持原划分。模拟扫描只是图像增强，不是真实扫描训练语料。数据构建命令与来源说明见 [data.md](../../docs/data.md)。

从 v2 LoRA 继续训练，8 张 H100，BF16、FlashAttention 2、rank 8/alpha 16、学习率 1e-5、每卡 batch 12，共两轮 496 步。语言与视觉部分使用 LoRA，投影层冻结。按验证损失选择第 400 步（0.00357315），并检查各字段生成指标及真实中文谱头，再运行独立测试。token 上限 1024，训练最大 901、验证最大 883，无截断。配置见 [training_config.yaml](training_config.yaml)，完整指标、哈希、选择及训练状态见 [evaluation.json](evaluation.json)。

## 真实验收与历史候选

先前直接扩充训练的 `glm_ocr_document_info_v3_lora` 在原生 GP 验证／测试上有提升，但把真实中文谱头的“中级课”误当作者，因此撤回默认并保留失败记录。本版恢复正确的“击弦练习曲／成田工作室／130”，也正确读取调弦标签；默认切换前已完成原图裁图验收。随后与最终小节候选及默认版面模型一起运行完整管线：真实扫描与三种原生中文排版的 GP5 标题、作者和速度全部正确；小节识别本身仍有单独的错误指标，详见机器记录。

这一页是本地验收样例，不代表真实扫描准确率。多语言、复杂署名、多作者和照片透视仍需人工检查；这里的作者目标来自 Guitar Pro 的 artist 字段，也不等同于所有排版中的作词／作曲／制谱人。旧 v2 与初版 v3 均保留供对照和回退。

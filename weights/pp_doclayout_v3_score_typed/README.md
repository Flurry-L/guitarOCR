# 小节定位与谱面类型联合检测

此为历史版本，当前默认模型见[模型目录](../README.md)。

一套 PP-DocLayoutV3 从页面图像同时预测小节框和谱面类型。类别为 `measure_tab`、`measure_notation`、`measure_both`、`tempo_region`。混合谱的一个小节框覆盖对应的五线谱与 TAB。模型无需接收谱面类型参数。

## 推理约定

检测结果保留类别、框、检测分数和 `mode=tab|notation|both`。页面类型按小节检测分数加权投票，文档类型按全部小节投票。`mode_vote_fraction` 是投票占比，不是校准后的分类概率。每个裁图自己的类型继续传给 GLM-OCR，文档汇总类型不会覆盖它。

命令行和新建网页项目默认使用自动谱面类型。自动模式会对包括矢量 PDF 在内的页面调用版面模型；显式选择谱线几何，或使用不输出类型的旧版两类模型时，才需要谱线规则提供类型。手动指定 `tab / notation / both` 会覆盖 OCR 使用的类型；自动模式下，也可在网页侧栏逐小节纠正类型。不同谱面类型之间切换时重置 OCR 的上一小节视觉上下文，避免把纯音高字段误当成弦品字段。

## 数据与训练

复用上一版统一定位模型的 Guitar Pro 8 原生渲染页面，仅按每页已有的 `mode` 改写小节类别；图像、框坐标和来源划分不变。没有重新渲染，也没有引入其他渲染器或人工猜测标签。训练为 600 个 family / 7,003 页，验证为 100 / 1,196，测试为 100 / 1,123。每个划分内三种小节类别的框数相同；训练每类 53,175 个，验证每类 9,161 个，测试每类 8,586 个。

来源分组及文件哈希见 [dataset_sources.json](dataset_sources.json)。测试来源来自原始 test 分组，并排除历史版面 inventory 的 family；本轮只按验证集选择检查点。不同 ID 的同曲内容无法仅靠文件标识完全去重。

初始化来自上一版两类模型最佳第 8 轮的 EMA 权重。将旧 `measure` 分类投影复制到三个小节类别，保留速度类别；其余 827 个张量不变。脚本 [initialize_typed.py](../../layout/initialize_typed.py) 保存原始与输出权重哈希和张量形状。

配置为 [train_typed.yaml](../../layout/configs/train_typed.yaml)，实际展开配置见 [training_config.yaml](training_config.yaml)。使用 8 张 H100，每 GPU batch 4，学习率 0.00005，预热 100 步，继续微调 8 轮；每轮按验证集四类 bbox AP 选择最佳模型。PaddlePaddle GPU 3.2.0、PaddleX 3.7.2、pycocotools 2.0.8。数据与训练复现命令见 [training.md](../../docs/training.md)。

最终选择第 7 轮，训练器记录的验证集四类 bbox AP 为 93.7982%。验证集 1,196 页的类型全部正确，IoU 0.50 成功匹配的 27,473 个小节类型全部正确。选择记录在运行独立测试前保存，测试集未参与检查点选择。

## 评测约定

[机器可读记录](evaluation.json) 保存模型／标注哈希、初始化记录、检查点选择和完整指标。定位 AP 将三种小节类别合并后计算，便于与旧两类模型比较；四类 AP 同时要求位置和类别正确。页面类型准确率采用模型小节结果的加权投票，漏检导致没有类型的页面也计入分母。推理阈值为 0.25，包含与实际流程一致的阅读顺序和谱线后处理。

## 独立测试结果

100 个测试 family，三种排版共 1,123 页。以下 AP 为 COCO AP@[0.50:0.95]，召回率采用 IoU 0.50；对照为上一版两类统一模型。

| 谱面 | 上一版小节 AP | 本版小节 AP | 小节召回率 | 小节数完全正确页面 | 页面类型正确 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 纯 TAB | 98.76% | 99.48% | 100.00% | 338 / 338 | 338 / 338 |
| 纯五线谱 | 93.68% | 94.35% | 99.92% | 288 / 293 | 293 / 293 |
| 五线谱＋TAB | 97.90% | 97.95% | 99.98% | 490 / 492 | 492 / 492 |

四类综合 AP 为 94.85%。页面类型准确率为 1,123 / 1,123；IoU 0.50 成功匹配的 25,749 个小节，其类型全部正确。类型准确率不表示没有漏框：测试集共有 25,758 个真实小节，未匹配小节的影响由召回率和 AP 体现。

旧稀疏 TAB 验证集共 989 页，全部判为 TAB，小节 AP 从上一版 98.52% 变为 98.66%；小节数完全正确页面从 987 降至 979，召回率从 99.99% 变为 99.96%（24,780 个小节中匹配 24,770 个）。三模式验证集的小节 AP 分别为 TAB 98.51%、五线谱 94.61%、混合谱 98.12%，与上一版相近；速度框 AP 从 85.70% 降至 83.51%。这些退步保留在评估记录中。

## 实际推理验收

使用项目默认权重、默认 Paddle CPU 环境和 `--mode auto --layout-source auto`，三种 GP8 矢量 PDF 样例各输出 4 个小节，页面和每个小节类型均正确。扫描样例 `jixian.pdf` 自动判为混合谱，输出 17 个小节；叠框图覆盖各小节对应的五线谱和 TAB。

验收时将谱线类型分类函数替换为一调用就报错，四份输入仍全部通过，确认类型来自模型。输入／权重 SHA-256、推理时间和结果路径见 `evaluation.json` 的 `cpu_acceptance`。62 项单元测试、3 项浏览器测试、Ruff 和环境／权重哈希检查通过。OCR 路由、类型切换及人工纠正由可控模型输出测试覆盖；本次真实样例验收仅运行版面阶段。

## 使用范围

训练和测试以规则排版的 Guitar Pro 页面为主。类型识别和定位指标不能代表任意拍照、手写、多音轨总谱，也不能当作音符、节奏或整谱转录准确率。本次没有更新 GLM-OCR 权重。多种谱面的小节记录可以在同一文档中传递和编辑，但同页混排并不是本次独立测试集覆盖的专门场景。

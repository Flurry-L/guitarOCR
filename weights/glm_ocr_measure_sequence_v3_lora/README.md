# 三种谱面的小节 OCR：扩充训练版

该 LoRA 读取 TAB、五线谱、混合谱小节及其前文，输出音符、节奏和奏法。谱面类型由 PP-DocLayoutV3 给出，小节与谱头任务共用一个 GLM 基座。

## 数据与训练

2,799 个音乐来源，训练／验证／测试为 2,400／199／200。全部使用 Guitar Pro 原生渲染，保持三种排版来自同一来源时处于相同划分。新增来源主要是真实 GP 文件，另有技巧合成 GP；它们不等同于真实扫描训练数据。

有效干净训练小节 587,019（每种模式 195,673），另加 89,318 条难例重复和 147,212 条模拟扫描退化，合计 823,549 条训练条目。剔除了 3 条损坏目标和 3 条含损坏前文的样本。完整验证 54,138、测试 49,551 条；实际模型对照使用下表的固定子集，不能将其表述成全量测试。来源隔离、标签哈希和生成命令见 [data.md](../../docs/data.md)。

从 v2 适配器继续训练，8 张 H100 80GB、BF16、FlashAttention 2、LoRA rank 8/alpha 16、学习率 2e-5、每卡 16 条、累积 2 步，全局批量 256。配置最多两轮，连续三个验证点不改善时早停：实际 5,000 步、约 1.55 轮、8,468 秒。按训练期间验证损失选择第 3,500 步（0.0327563），冻结后才运行独立测试。最大输入长度 2,102，低于 3,072 上限，无截断。配置见 [training_config.yaml](training_config.yaml)，完整结果和选择记录见 [evaluation.json](evaluation.json)。

## 小节表示与范围

小节文本使用 `MEASURE`、前文显示为 `CONTEXT`，与内部协议和旧文件兼容。修复空小节休止、前文拍号／调号延续、失败占位后的 swing 状态延续、可见装饰音参数和常见推弦轮廓；严格处理未知／重复元数据、重复或超出 GP5 能力的声部、显式时间空隙及不可演奏音高，避免导出时静默丢失。3,084 个验证小节从文本导出 GP5 再解析的对照，音符、节奏和已编码奏法全部一致。

小节文本不是 GP 全部播放参数的无损存档。力度符号尚未按实际打印位置监督；本轮选择语料的 trill 标签为 0，语法／导出支持不代表已训练出识别能力；任意推弦控制点仍不完整覆盖。训练与评估以规则 Guitar Pro 单轨吉他谱为主，手写、透视照片和复杂多音轨总谱需要额外验证。格式合法也不表示音乐内容完全正确。细节见 [小节文本格式](../../docs/score-text.md)。

默认路径更新后，已再次使用未指定适配器的 CLI 完成 `jixian.pdf` 全流程：17/17 核心及完整匹配、元数据正确、全部首次解码通过。81 项单元测试、3 项浏览器测试、Ruff、CUDA 环境和默认权重 SHA-256 校验通过。
